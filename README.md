# DitherLab

**DitherLab** — браузерный редактор для дизеринга, полутонов, пиксельных текстур, геометрических паттернов и ASCII-графики. Приложение работает локально в браузере: выбранные изображения не отправляются на сервер.

## Запуск в браузере

После однократного включения GitHub Pages откройте **[DitherLab Web](https://moroskinbiba-crypto.github.io/521252/)**. Никакая установка не нужна.

### Однократная настройка GitHub Pages

Открыть [Settings → Pages](https://github.com/moroskinbiba-crypto/521252/settings/pages) и в разделе **Build and deployment → Source** выбрать **GitHub Actions**. После этого workflow автоматически проверяет JavaScript и публикует сайт при каждом обновлении ветки `main`.

Сейчас автоматическая активация Pages через подключение GitHub заблокирована правами GitHub App («Resource not accessible by integration»), поэтому этот переключатель нужно включить один раз вручную. Сборка сама сообщит о проблемах, если появятся.

## Возможности

- Floyd–Steinberg и Atkinson error diffusion.
- Ordered dithering: Bayer 2×2, 4×4 и 8×8.
- Halftone, pixel poster и геометрические Shape Lab-формы.
- Палитры, монохромный и двухцветный режимы.
- Контраст, яркость, порог, размер ячейки, тональные уровни, размытие и инверсия.
- Постэффекты: CRT scanlines, glow, chromatic shift, vignette и noise.
- ASCII Studio с несколькими наборами символов и экспортом TXT/PNG.
- Восемь встроенных стартовых пресетов и пользовательские пресеты.
- Пакетная обработка нескольких изображений.
- Экспорт PNG/JPEG, копирование PNG в буфер, сохранение и открытие проектного JSON.
- Кнопка **↓ HTML** скачивает автономную версию: её можно открыть локально без установки.
- PWA-манифест и офлайн-кэш для поддерживаемых браузеров.

## Скачать приложение

1. Откройте веб-приложение.
2. Нажмите **↓ HTML**.
3. Сохраните `ditherlab-offline.html` и открывайте его в современном браузере. Основной редактор работает без интернета.

Также можно скачать весь исходный код через **Code → Download ZIP** на GitHub.

## Локальный запуск

Для обычной обработки можно открыть `index.html` напрямую. Для проверки установки PWA и service worker запустите статический сервер, например:

```bash
python -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Архитектура и ограничения

Приложение не требует сборщика и внешних JavaScript-библиотек: интерфейс, CSS и алгоритмы находятся в `index.html`. Это упрощает GitHub Pages и автономное скачивание.

Это самостоятельная реализация художественного редактора, а не копия закрытых алгоритмов Dither Boy. Видео-таймлайн, полный набор из 63 алгоритмов, импорт пользовательских фигур и SVG-экспорт пока не реализованы. Обработка происходит на стороне клиента; очень большие изображения могут временно потреблять много оперативной памяти.
